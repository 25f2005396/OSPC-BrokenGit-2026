# Contribution instructions

1. Fork this repository; create a branch named `fix/issue-id-short-description`.
2. Select ONE issue in your assigned track. Multiple candidates may choose the same issue.
3. Make the smallest correct change; add or update tests where applicable.
4. Run `python -m pytest` and document the outcome.
5. Open ONE PR against `main` using the provided template. Do not merge your PR.
6. Submit your PR link through the organizer's form within 24 hours.

Do not edit tests to conceal failures. AI tools are permitted if disclosed. Be ready to explain your work live.
